# AI Agent Guidelines

## MANDATORY Styling Rules

#### 1. Use Tailwind CSS exclusively for ALL styling (layout, typography, animations, everything).

**Before using ANY alternative** (custom CSS, inline styles, CSS-in-JS, etc.):

- **ASK permission EVERY TIME - no exceptions**
- Explain why Tailwind cannot accomplish it
- Wait for explicit approval

#### 2. Use DaisyUI themes only for ALL colors (defined in styles.css).

**Before using ANY custom color:**

- **ASK permission EVERY TIME**
- Explain why DaisyUI themes cannot handle it
